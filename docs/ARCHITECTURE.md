# Architecture

## 목적과 경계

Basic ML API는 단일 프로세스 모듈러 모놀리스입니다. HTTP, 아카이브 검증, 모델 수명주기, 공통 기반 코드를 분리하되 분산 시스템처럼 가장하지 않습니다.

의존 방향은 다음 한 방향을 유지합니다.

```text
src/main.py -> src/api -> src/core -> src/common
```

`src/core`는 Flask 요청 객체를 알지 않습니다. `src/api`는 파일 교체나 캐시 내부 구조를 직접 조작하지 않습니다.

## 구성 요소

### `src/main.py`

애플리케이션 조립 지점입니다. 설정을 읽고 `ModelManager`를 `app.extensions`에 등록하며 Blueprint, 오류 처리기, 리소스 모니터를 연결합니다. 비즈니스 규칙은 두지 않습니다.

### `src/api/`

HTTP 경계입니다.

- 요청 형식과 필수 값을 검증합니다.
- 코어 호출 결과를 `data` 응답으로 변환합니다.
- `ApplicationError`와 프레임워크 오류를 안정적인 오류 계약으로 변환합니다.
- 전역 상태 대신 `current_app.extensions["model_manager"]`를 사용합니다.

### `src/core/model_archive.py`

ZIP 입력의 보안 경계입니다.

- 엔트리 개수와 총 압축 해제 크기를 제한합니다.
- 절대 경로, 상위 디렉터리 이동, 역슬래시 경로, 심볼릭 링크를 거부합니다.
- 파일/디렉터리 충돌과 손상된 압축 데이터를 거부합니다.
- 최소 하나의 일반 `.keras` 파일을 요구합니다.

아카이브 정책을 바꾸는 코드는 이 모듈과 해당 회귀 테스트에 함께 둡니다.

### `src/core/model_manager.py`

모델 저장소의 상태 전이를 소유합니다.

- 시작 시 저장소 복구와 모델 등록(심볼릭 링크 디렉터리·파일 제외)
- 임시 작업공간에서 검증한 모델의 원자적 교체
- 프로세스 로컬 LRU 캐시
- 예측과 마지막 사용 시각 갱신
- 오래된 모델과 지연된 백업 제거

### `src/core/model_types.py`

코어 결과 타입과 모델 출력의 JSON 변환을 담당합니다. NumPy/TensorFlow 값은 중첩 구조를 보존하면서 JSON 값으로 바꾸고, 비유한 수와 지원하지 않는 타입은 거부합니다.

### `src/common/`

도메인에 공통인 작은 기반만 둡니다.

- `clock.py`: timezone-aware UTC 시각과 보존 기간
- `errors.py`: 내부 오류 코드와 세부 정보
- `metrics.py`: 프로세스 로컬 Prometheus 계측

## 주요 흐름

### 업로드

1. API가 파일, 해시, 전송 크기를 검증합니다.
2. `ModelManager`가 해시별 락을 얻고 저장소 안에 임시 작업공간을 만듭니다.
3. `model_archive`가 ZIP을 검증하고 임시 디렉터리에 추출합니다.
4. 추출한 모델을 예측과 동일한 로더로 검증합니다. 실패 시 기존 상태는 변경되지 않습니다.
5. 기존 디렉터리가 있으면 백업 이름으로 원자적 이동합니다.
6. 새 디렉터리를 최종 경로로 원자적 이동합니다.
7. 실패하면 기존 디렉터리를 복구합니다. 성공하면 이전 캐시 항목을 무효화합니다.

프로세스가 교체 도중 종료되면 다음 시작 시 `@backup-*`와 `@upload-*` 상태를 정리하거나 복구합니다.

### 예측

1. API가 JSON 배열을 NumPy 배열로 변환합니다.
2. `ModelManager`가 해시별 락 아래 캐시를 확인합니다.
3. 캐시 미스면 결정적인 파일 순서로 `.keras` 파일을 선택합니다.
4. Keras 모델을 `compile=False`, `safe_mode=True`로 로드합니다.
5. LRU 캐시에 넣고 마지막 사용 시각을 UTC로 갱신합니다.
6. 예측 결과를 JSON 호환 타입으로 변환합니다.

## 동시성 불변조건

- `_state_lock`은 메타데이터, LRU 순서, 캐시 항목을 함께 보호합니다.
- 해시별 `RLock`은 같은 모델의 업로드·로드·정리가 서로 교차하지 않게 합니다.
- 해시별 락은 `WeakValueDictionary`에 보관해 존재하지 않는 해시 요청이 상태를 무한히 늘리지 않게 합니다.
- 디스크 작업은 전역 상태 락 밖에서 수행하고, 상태를 다시 반영하기 전에 경로와 메타데이터가 바뀌지 않았는지 확인합니다.
- 캐시 크기와 메트릭은 같은 상태 변경 구간에서 갱신합니다.

이 규칙을 바꾸는 변경은 반드시 동시성 테스트와 실패 복구 테스트를 추가해야 합니다.

## 시간과 영속성

내부 시각은 모두 timezone-aware UTC입니다. API의 `used` 값은 ISO 8601 문자열입니다. 현재 메타데이터는 메모리에만 있으며 재시작 시 모델 디렉터리에서 다시 구성됩니다. 정확한 마지막 사용 시각을 재시작 후에도 보존해야 한다면 별도 영속 저장소가 필요합니다.

## 프로세스 모델

현재 캐시, 메타데이터, 락, 정리 스케줄러는 프로세스 로컬입니다. 따라서 배포 명령은 Gunicorn worker를 1개로 고정합니다. 수평 확장 전에 다음을 외부화해야 합니다.

- 모델 메타데이터와 마지막 사용 시각
- 모델 교체/정리를 위한 분산 조정
- 공유 객체 저장소 또는 일관된 볼륨 정책
- worker별 캐시와 메트릭의 의미

## 변경 가드레일

- 공개 URL, 성공/오류 envelope, `error.code`를 바꾸면 `docs/SPEC.md`와 계약 테스트를 함께 바꿉니다.
- HTTP 파싱은 `src/api`, ZIP 정책은 `model_archive`, 상태 전이는 `model_manager`에 둡니다.
- 새 시간 값은 UTC이고 naive `datetime`을 만들지 않습니다.
- 새 의존성은 책임 경계를 단순화하거나 검증 가능성을 높이는 경우에만 추가하고 `uv.lock`을 갱신합니다.
- README에 구현 세부를 복제하지 않습니다. 사용법은 README, 계약은 SPEC, 내부 구조는 이 문서가 소유합니다.
